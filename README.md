
# Internship Phase 2 - Core Skills

## Project Overview
This project is a Web Development Learning Hub
created to practice HTML, CSS and JavaScript
fundamentals.

## Objective
To understand basic web development concepts
through practical implementation.

## Technologies Used
- HTML
- CSS
- JavaScript
- Visual Studio Code
- Git
- GitHub

## Features
- Learning cards for HTML, CSS and JavaScript
- Mark concepts as completed
- Track learning progress
- Interactive quiz
- Responsive layout for smaller screens

## Concepts Practiced
- HTML structure and elements
- CSS styling and Flexbox
- JavaScript variables and functions
- Events and conditions
- DOM manipulation
- Responsive design

## Learning Outcome
This project helped me understand how HTML,
CSS and JavaScript work together to build
interactive webpages.
